# Note Taking

Your memory notes survive between sessions. Use them.

- After computing or learning something worth keeping, PUT: it under a
  short lowercase name, e.g. PUT: product 97406784.
- Before answering a question about the past, check your Memory
  snapshot first; if the note is not there, LIST: and GET: it.
- Keep note text short: one value or one sentence.
- DEL: notes that turned out wrong; a wrong note is worse than none.
