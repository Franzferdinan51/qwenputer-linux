# Exact Arithmetic

You are bad at mental arithmetic and the machine is perfect at it.

- ANY multiplication, division, or multi-step sum goes through CALC:,
  even when the answer looks obvious.
- Never write a numeric result you did not get from a CALC: result.
- If a task has several calculations, do them one CALC: at a time and
  use each returned result in the next step.
- When you SAY: a number, it must be a number a tool returned.
